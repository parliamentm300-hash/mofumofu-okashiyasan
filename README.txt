# もふもふ おかしやさん / GitHub Pages 公開用

このフォルダ内の全ファイルを新しいGitHubリポジトリのトップ階層へアップロードしてください。**ZIPファイル自体ではなく、中の5ファイル**をアップロードします。

1. GitHubで新しいPublicリポジトリ（例: mofumofu-okashiyasan）を作成。シチュエーション工房の既存リポジトリは使いません。
2. Add file → Upload filesから index.html、manifest.webmanifest、icon-192.png、icon-512.png、apple-touch-icon.png をアップロードしてCommit changes。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 公開URLが表示されたらAndroidはChrome、iPhoneはSafariで開きます。
5. iPhone: Safariの共有メニュー → ホーム画面に追加。Android: Chromeのメニュー → ホーム画面に追加（表示が異なる場合があります）。

注意: 公開リポジトリにしたファイルは一般に閲覧可能です。URLを知る人だけに限定するアクセス制御はありません。ゲームの進行記録は各端末のブラウザ内に保存され、端末間では同期されません。ゲーム内の広告・課金・外部APIはありません。オフライン動作は保証していません。
